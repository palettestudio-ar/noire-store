# Imágenes

Poné las fotos acá con estos nombres exactos y se aplican solas
(no hay que tocar el CSS). Mientras un archivo no exista, se muestra
un degradado de reemplazo del mismo tono.

| Archivo          | Dónde se usa                          | Formato sugerido |
|------------------|---------------------------------------|------------------|
| `hero-1.jpg`     | Portada, slide 01 (The After Hours)   | 2400×1600 horizontal |
| `hero-2.jpg`     | Portada, slide 02 (Quiet Luxury)      | 2400×1600 horizontal |
| `hero-3.jpg`     | Portada, slide 03 (Night Stories)     | 2400×1600 horizontal |
| `look.jpg`       | Shop the Look, foto central           | 900×1200 vertical |
| `p-blazer.jpg`   | Shop the Look, miniatura 1            | 300×400 vertical |
| `p-trouser.jpg`  | Shop the Look, miniatura 2            | 300×400 vertical |
| `p-bag.jpg`      | Shop the Look, miniatura 3            | 300×400 vertical |
| `p-boots.jpg`    | Shop the Look, miniatura 4            | 300×400 vertical |
| `new-1..5.jpg`   | Carrusel New In                       | 750×1000 vertical |
| `coll-1..3.jpg`  | Colecciones                           | 800×1100 vertical |
| `news.jpg`       | Newsletter                            | 1200×1200 |

Las posiciones de los puntos (`+`) sobre la portada están en
`index.html`, en el atributo `style` de cada `.hotspot`:
`--x` = posición horizontal, `--y` = vertical, ambas en %.
Cuando cargues las fotos reales, ajustá esos valores para que cada
punto caiga sobre la prenda correcta.
